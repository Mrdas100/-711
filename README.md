# جاهز للزواج — تطبيق PWA

تطبيق عربي متجاوب لجدول 30 يوما قبل الزواج مع نتائج InBody الأساسية وتمارين وتغذية ومتابعة الوزن والخصر ونسبة الدهون والخطوات والبروتين والماء والنوم

## التثبيت والنشر

1. فك ضغط ZIP
2. ارفع **محتويات** المجلد `jahiz_pwa` كاملة إلى استضافة ملفات ثابتة تدعم HTTPS مثل Netlify أو Vercel أو GitHub Pages
3. افتح رابط الموقع على iPhone باستخدام **Safari** ثم مشاركة ← إضافة إلى الشاشة الرئيسية
4. افتح التطبيق مرة متصلا بالإنترنت لتخزين الموارد ثم يمكن استعماله دون اتصال بعد ذلك

مهم: لا يمكن تثبيت PWA بشكل صحيح عند فتح `index.html` مباشرة من تطبيق «الملفات» (`file://`) لأن الخدمة دون اتصال تتطلب HTTPS أو localhost

## الخصوصية والنسخ الاحتياطي

كل المعلومات تبقى على الجهاز عبر LocalStorage ولا توجد خوادم لحفظ السجلات ولا أدوات تتبع
تغيير الجهاز أو تنظيف بيانات Safari قد يحذف التقدم لذا استخدم «نسخة احتياطية» من صفحة النتائج للحفظ الدوري ثم «استيراد نسخة» للاستعادة

## نقاط طبية

الخطة تنظيمية لا تمثل تشخيصا أو علاجا
السعرات المبدئية 1700 قابلة للتغيير حسب الاستجابة بعد أسبوعين إلى ثلاثة مع المراقبة
فحص InBody تقديري وقد يتغير باختلاف مستوى السوائل؛ يفضل متابعة طبيب أسرة بسبب ارتفاع مؤشرات الدهون الواردة في التقرير
تجنب التجويع والتجفيف ومحاولة خسارة 10 كجم خلال شهر

## التطوير

التطبيق بلا اعتماديات خارجية ويعمل بملفات HTML CSS JavaScript وخدمة عامل Service Worker
